# Name

Vehicle Settings Copy

# Mod reference

VehicleSettingsCopy

# SHORT DESCRIPTION

Copy and paste a truck's, tractor's or explorer's timetable stops and fuel onto other vehicles. Pasting fills the fuel slot from your inventory.

# FULL DESCRIPTION

See `FullDescription.md`.

# SOURCE

https://github.com/benvrakas/VehicleSettingsCopy

# NETWORK ACTIVITY TRANSPARENCY

This mod makes no network connections of its own. When you press Paste, your game sends the copied stops and fuel type to the server through the game's own multiplayer connection.
